Submission Requirements
●​ Submit up-to 5 submissions ie 5 max. per person (must use a different site for each)
○​ Submit 1 minimum but to submit more than 1 entry please submit the form
multiple times
●​ All submissions must be implemented as functional web app
○​ The entire code must be contained in a single HTML / webpage
○​ You don't need a back-end and can use fake/mock data
●​ You must resemble the original site as closely as possible.
○​ Fonts, spacing, layout, colors, number of elements – it all matters
●​ You must add something new to the site you are replicating

○​ This could be a feature, component, any change that would make the site better
○​ The more complex the better!
●​ All submissions must include a link to your web app (ie host it Vercel, Github Page etc)
○​ We need to test it!
○​ Finalists will have to share a link to their Github repo (ie verify you built it)
○​ If there is a tie between Finalists for a prize, code quality will determine the
winner
●​ Submit via the official form: https://form.typeform.com/to/lJqN5mmS

Eligibility:
●​ Open to individual participants worldwide but some country restrictions apply (see

●​ All skill levels welcome
●​ You must be 18 years of age or over

Allowed Tools & Resources
●​ Using LLM-powered code editors/IDEs (GitHub Copilot, Cursor, Windsurf) is permitted
